## 企业简介

麦迪森生物科技集团（Madison Biomedical Corporation）是旧世界最具影响力的生物医学企业之一。

公司成立初期专注于创伤治疗、器官修复以及神经恢复技术。随着再生医学的发展，麦迪森逐渐进入生命模板、细胞重构以及人体重建技术领域。

其研究成果成为梦屿生命保障体系的重要技术来源之一。

## 核心项目

### Life Template Project

生命模板计划。

研究目标：
建立完整的人体信息记录与重构技术。

该项目后来成为梦屿重生系统的重要基础。

## 与梦屿关系

麦迪森生物科技集团曾参与梦屿生命模板技术合作项目。

灾难发生后，大量实验资料、研究设备以及设施记录失联。

部分研究设施目前被列入高风险区域档案。
