## 企业简介

麦迪森生物科技集团是旧世界最具影响力的生物医学企业之一。

公司早期专注于创伤治疗、器官修复以及神经恢复技术，随后逐渐参与生命模板与重生技术研究。

其研究成果成为梦屿生命保障体系的重要基础。

## 企业理念

"Death is not an ending. It is a problem waiting to be solved."

死亡不是终点，而是一个等待被解决的问题。
