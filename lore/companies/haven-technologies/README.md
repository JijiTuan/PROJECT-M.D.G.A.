## 企业简介

海雾科技集团（Haven Technologies Corporation）是旧世界领先的智能基础设施企业。

公司负责开发城市级人工智能系统、能源调度网络、自动化管理平台以及生命保障相关基础设施。

其技术曾应用于大型城市、公共设施以及特殊研究区域。
