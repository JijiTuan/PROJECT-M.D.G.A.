## 企业简介

均克饮品集团（Junko Beverage Corporation）是旧世界大型饮品企业之一。

公司主要生产日常饮品、功能饮料以及长期储存型饮品。

其产品曾广泛分布于城市便利店、公共设施、商业中心以及应急储备中心。

## 灾后记录
