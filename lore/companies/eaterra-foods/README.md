## 企业简介

益特食品集团（Eaterra Foods Corporation）是旧世界最大的综合食品企业之一。

公司业务覆盖日常食品生产、长期储存食品、营养强化产品以及灾害保障食品供应。

不同于传统食品企业，益特长期致力于解决极端环境下的人类营养需求问题。
