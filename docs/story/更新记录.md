# 剧情文档更新记录

## 0.3.0

- 正式补充人类逐光联合会的成立背景。
- 明确逐光会由梦屿多个公共机构在危机中临时组成。
- 明确逐光会最初确实拯救过梦屿，并约定在危机后归还紧急权力。
- 补充紧急状态长期延续、救援分类固化和权力集中的过程。
- 确立守望派、秩序派、治疗派和强硬派四种内部路线。
- 补充逐光会对稳定感染者资料、扩岸计划和外缘居民的内部分歧。
- 明确逐光会既可能改革，也可能走向永久管制。
- 正式补充生命模板、重生节点和重生点数的世界观解释。
- 明确感染者重生需要额外校正，因此消耗高于幸存者。
- 明确玩家可以额外消耗重生点数保留物品栏。
- 明确点数扣至 `0` 时当前重生仍可完成，下一次死亡才会失去重生能力。
- 明确完整重生技术主要由梦屿掌握，旧世界只有少量机构和特殊人员拥有。
- 更新术语表和剧情文档版本号。

## 0.2.0

- 明确梦屿是一片真实建立起来的乌托邦。
- 明确梦屿的边界来自客观承载能力，而不是对人的价值筛选。
- 补充梦屿与旧世界两种制度之间的长期抗争。
- 正式加入外缘带的自然形成背景。
- 明确外缘带不是梦屿主动建立的贫民区，也不是统一行政区域。
- 补充旧世界企业进入外缘带并带回旧有分配制度的过程。
- 正式加入梦屿主动提出的扩岸计划。
- 记录扩岸计划受到旧世界企业和政治机构阻挠，并在危机前尚未完成。
- 将梁砾确定为来自外缘带、曾接近获得梦屿完整保障的人物方向。
- 更新术语表中的梦屿、旧世界、外缘带与扩岸计划定义。
