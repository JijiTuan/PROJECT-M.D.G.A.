# 剧情文档更新记录

## 0.4.0

- 正式建立白芷完整人物档案。
- 确定白芷为 26 岁、出生于梦屿的年轻感染科医生。
- 明确白芷是梦屿公共教育和医疗体系培养出的第一代医生之一。
- 补充白芷选择医学、参与危机医疗和负责长期随访的经历。
- 明确白芷通过重复随访发现“长期稳定感染状态”，但不主张所有感染者都安全。
- 补充白芷年轻带来的质疑勇气、性格习惯、程序违规风险和政治判断不足。
- 加入白芷曾支持降低隔离限制、患者随后短暂失控并导致医护人员受伤的错误经历。
- 确定江晚是白芷专业培训和病例评审上的半导师。
- 明确江晚与白芷围绕公开时机、样本充分性和公共风险产生分歧。
- 补充逐光会逐步修改报告、限制权限、调离项目和开展纪律调查的冲突过程。
- 补充白芷第一次与玩家见面的候选场景，以及玩家行为影响其信任的原则。
- 更新人物索引、结构化人物数据和人物关系数据。
- 文档版本更新为 `0.4.0`。

## 0.3.0

- 正式补充人类逐光联合会的成立背景。
- 明确逐光会由梦屿多个公共机构在危机中临时组成。
- 明确逐光会最初确实拯救过梦屿，并约定在危机后归还紧急权力。
- 补充紧急状态长期延续、救援分类固化和权力集中的过程。
- 确立守望派、秩序派、治疗派和强硬派四种内部路线。
- 补充逐光会对稳定感染者资料、扩岸计划和外缘居民的内部分歧。
- 明确逐光会既可能改革，也可能走向永久管制。
- 正式补充生命模板、重生节点和重生点数的世界观解释。
- 明确感染者重生需要额外校正，因此消耗高于幸存者。
- 明确玩家可以额外消耗重生点数保留物品栏。
- 明确点数扣至 `0` 时当前重生仍可完成，下一次死亡才会失去重生能力。
- 明确完整重生技术主要由梦屿掌握，旧世界只有少量机构和特殊人员拥有。
- 更新术语表和剧情文档版本号。
