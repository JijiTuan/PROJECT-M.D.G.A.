## 梁朔当前确认关系

- **梁朔 → 扩岸过渡社区**：在此生活、工作，并在危机刚爆发时选择留下维持居民生存设施。
- **梁朔 → 旧世界企业**：企业是危机前雇主，但留守是为了普通居民，不是保护企业资产。
- **逐光会 → 梁朔**：刚成立时承诺等待无法立即撤离的人；后续是否履行由剧情决定。
- **梦屿 → 梁朔**：扩岸计划已准备接纳其本人和社区，危机打断最后程序。
- **玩家 → 梁朔**：保存广播、维修日志、居民证词和预登记资料会影响其最终处境。
