# 故事阶段

状态：**已确认总体方向，具体事件待设计**

阶段由服主手动切换。任务进度达到 `100%` 不会自动进入下一阶段。

## 第一阶段：余梦期

玩家刚来到梦屿，主要进行：

- 开荒；
- 建家；
- 挖矿；
- 种田；
- 制作武器；
- 探索废墟；
- 抵御丧尸。

剧情只进行弱引导。

逐光会最初看起来像是在保护秩序。早期证据也容易让人相信感染者非常危险。

第一名真人感染者出现后，逐光会发布感染确认广播。

### 阶段功能

- 建立玩家自己的日常生活和社区。
- 让玩家先相信现有秩序具有必要性。
- 让医院、避难所、哨站等玩家建筑逐渐拥有剧情用途。
- 避免开服后立即大量抛出世界观说明。

## 第二阶段：管制期

逐光会加强：

- 身份登记；
- 感染筛查；
- 隔离；
- 治疗；
- 信息管理。

解药确实有效，因此“让感染者恢复成幸存者”看起来是最合理的道路。

医生 NPC 白芷发现部分感染者并没有继续恶化。她整理长期病例后，被逐光会以传播未经确认信息为由带走或失踪。

### 阶段功能

- 让治疗路线拥有真实效果，而不是显然错误的骗局。
- 使玩家在自由、安全、医疗伦理和公共风险之间产生分歧。
- 通过白芷事件建立第一次明显的官方口径裂缝。
- 让玩家开始判断：逐光会是在保护社会，还是在控制“什么可以被相信”。

## 第三阶段：疑光期

丧尸对幸存者的威胁显著增加，但对感染者反应较弱。

感染者也更适合进入污染区。

逐光会开始：

- 回收长期记录；
- 封锁档案；
- 否认感染者适应性；
- 收紧对相关研究的解释权。

逐光会部分成员开始怀疑：自己保护的是梦屿，还是逐光会希望人们相信的秩序。

核心问题从“是否治愈感染者”转变为：

> 人类应该消灭感染，还是理解并稳定感染？

### 阶段功能

- 用实际玩法证明感染不只是一种纯粹退化。
- 让玩家交叉验证前期线索。
- 使逐光会内部出现可以被玩家观察和影响的分歧。
- 开放高代价主动感染的可能性。
- 让玩家自己的信息传播方式也接受道德检验。

## 第四阶段：破晓期

重生系统越来越不稳定。

最终核心区域可能只有感染者能够进入；幸存者则需要在外围：

- 维修设备；
- 校准重生系统；
- 解码资料；
- 提供火力；
- 维持设施；
- 保护通信和能源链路。

### 当前好结局方向

好结局不是所有人恢复成幸存者，也不是所有人变成感染者。

感染者进入核心污染区，幸存者在外围维持系统，双方共同完成稳定方案和重生校准。

- 全员治愈会使梦屿失去适应未来的可能。
- 全员感染会失去部分维持文明和控制变化的能力。
- 真正的好结局要求不同身份的人承认彼此并密切合作。

### 最终行动规则

- 只统计真正参加行动并完成关键行为的玩家。
- 错误方案会先进入试运行并产生警告。
- 玩家在了解异常后仍正式提交，才会确定不可轻易撤销的结局。
- 最终答案不应只存在于文件或 NPC 口述中，应由玩法机制实际证明。
- 结局后不清档，事件结果进入服务器长期历史。
