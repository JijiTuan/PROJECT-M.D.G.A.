## 核心创作判断

**玩家没有剧本，世界有作者。**

玩家可以不参与主线，并继续正常生存、建设、交易、探索与社交。剧情需要进入玩家已经建立的生活，而不是取代 Minecraft 的自由玩法。

## 当前开服切片

当前只运行两个阶段：

1. **梦的开始**：抵达阿拜多斯 → 白芷 → 周岑 → 选择加入或保持独立；加入者领取补给并参与逐光会基地建设。
2. **余梦期**：逐光会公开救治公告 → 白芷私信 → 医疗接待点与江晚复核 → 药剂/面具流程；阶段开场两游戏日后发布丧尸记忆公告并开启丧尸挖掘。

阶段由服主手动切换，任务完成率不会自动切换阶段。随机线索、投票和后三个阶段暂未接入代码。
右下角提醒会逐条显示所有未读公告的标题，正文仍通过终端公告详情查看。

## 开场时间基线

玩家进入游戏时，丧尸危机刚刚爆发，逐光会也刚刚成立。

玩家将亲眼参与最初的救援与建设，并影响逐光会之后是继续忠于梦屿、接受监督，还是在持续危机中逐渐走向权力集中。
