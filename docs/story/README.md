这里记录的是“当前讨论结果”，不是不可修改的最终设定。后续随着玩法验证、代码实现、玩家行为和服主判断，内容可以继续修订。

## 核心创作判断

**玩家没有剧本，世界有作者。**

玩家可以不参与主线，并继续正常生存、建设、交易、探索与社交。剧情需要进入玩家已经建立的生活，而不是取代 Minecraft 的自由玩法。

模组内容构成玩家的日常生活；剧情事件改变这些生活的意义。玩家应先建立一个值得守护的世界，之后再面对它应该变成什么样的问题。
