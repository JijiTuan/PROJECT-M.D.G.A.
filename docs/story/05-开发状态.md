# 当前开发状态

状态：**DreamingFishCore 1.21.1 当前开服切片**

## 已完成的底层内容

- 服务端权威的全服故事阶段系统。
- 阶段 ID、数字编号和显示名称。
- 两个独立 Java 阶段脚本：`OpeningStory`、`AfterdreamStory`。
- 文案 JSON（标题、正文、对白）与 Java 流程分离。
- 故事世界状态持久化。
- 第一阶段“抵达阿拜多斯 → 白芷 → 周岑 → 入会选择 → 建设引导”。
- 第二阶段“公开救治公告 → 白芷私信 → 江晚复核 → 药剂/面具”。
- 第二阶段加载后两游戏日丧尸记忆公告与 `digging` 能力开启事件。
- 成功和失败任务结果。
- 任务结算时的在场玩家记录。
- 全服进度和个人调查进度数据。
- 世界旗标、内容轮次、热重载和历史记录基础。
- 官方任务地点的选区、保存、保护和玩家收集。
- 玩家进入任务地点后自动切换冒险模式，离开后恢复。
- 任务地点保护建筑、容器、NPC 和装饰实体，但允许战斗。
- 中上方、左上角和右上角通知系统。
- 现有 NPC、随记本、终端和旧任务系统基础。

- NPC 临时驻地；
- 线索存放和公开调查。
