## 推荐的人物档案结构

每名重要人物建议至少记录：

1. 基础身份。
2. 玩家第一次见到他/她时正在做什么。
3. 公开立场。
4. 隐藏信息。
5. 真正恐惧。
6. 个人欲望。
7. 道德底线。
8. 最大弱点。
9. 会向玩家提出什么决定。
10. 会在什么条件下改变立场。
11. 不同阶段的状态。
12. 与玩家好感度、证据和世界旗标的关系。

## 好感度原则

好感度不应简单等同于“真相解锁进度”。

NPC 是否提供信息，还应考虑：

- 玩家是否带来了可靠证据；
- 玩家是否选择性展示资料；
- 玩家是否曾泄露秘密；
- 社区是否伤害过该人物关心的人；
- 玩家在相关事件中是否承担责任；
- 世界状态和故事阶段；
- NPC 自己的立场是否因后果发生变化。
