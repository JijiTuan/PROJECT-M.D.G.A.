## 人物档案原则

重要人物应记录基础身份、公开立场、隐藏信息、真正恐惧、个人欲望、道德底线、最大弱点、阶段状态，以及玩家证据和行为如何影响其立场。

好感度不应简单等同于真相解锁进度。
