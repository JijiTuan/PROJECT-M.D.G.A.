# 白芷

状态：**人物核心方向已确认，失踪过程与后期去向待设计**

## 一、基础档案

| 项目 | 信息 |
|---|---|
| 姓名 | 白芷 |
| 性别 | 女 |
| 年龄 | 26 岁 |
| 生日 | 5 月 9 日 |
| 血型 | O 型 |
| 婚姻状况 | 未婚 |
| 出生地 | 梦屿 |
| 最高学历 | 梦屿医学院临床医学硕士 |
| 专业方向 | 感染医学、神经感染、感染者康复与长期随访 |
| 职业 | 梦屿中央医院感染医学科住院医师 |
| 兼任职务 | 感染者治疗后长期随访项目执行员 |
| 所属体系 | 危机后纳入逐光会医疗管理体系 |

## 二、人物定位

白芷是一名年轻的感染科医生，也是第一批真正由梦屿公共教育和医疗体系培养出来的医生。

她没有显赫家庭，也不是被特殊选中的天才。她能成为医生，本身就是梦屿理想曾经真实存在的证明。

她的父亲是公共交通线路维护员，母亲曾在社区学校教授基础科学。按照旧世界的生活条件，白芷很可能无法承担漫长的医学教育，也不会拥有足够时间完成临床训练。

但在梦屿，她不需要先证明家庭拥有足够财富，才有资格学习医学。

因此，白芷对梦屿有一种近乎本能的信任。她相信梦屿的制度可能犯错，但也相信一个真正的梦屿应该允许普通人指出错误。

> “如果我们的结论错了，就应该修改结论。为什么承认错误，反而会被认为是在破坏秩序？”

## 三、为什么选择医学

白芷选择医学，并不是因为经历过某场戏剧性的家庭悲剧。

她小时候身体较弱，经常出入社区诊所。她记得的不是昂贵设备，而是一位社区医生愿意蹲下来，认真向年幼的她解释身体为什么会疼、药物为什么有效，以及恐惧并不意味着她正在失去控制。

这段经历让她认为，医生最重要的工作不仅是消灭疾病，也是帮助一个人重新理解自己的身体。

她后来选择感染医学，也是因为感染会同时改变身体、身份和人与人之间的关系。

在她看来，一个感染者面对的并不只有症状，还有：

- 对失控的恐惧；
- 家人和朋友的怀疑；
- 被隔离后的孤独；
- 对自身人格是否仍然完整的怀疑；
- 被社会重新定义的风险。

因此，她习惯把病人称为“患者”或直接称呼姓名，而不是使用编号和风险等级代替一个人。

## 四、危机初期的白芷

丧尸危机爆发时，白芷还没有完成全部高级临床资格。

因为医生严重不足，她被提前派往感染隔离区，负责：

- 记录感染者生命体征；
- 协助使用治疗药物；
- 与患者家属沟通；
- 整理治疗反应；
- 追踪患者出院或转移后的状态。

年轻意味着她缺少处置大型危机的经验。

她见过感染者失控，也亲眼见过医护人员因判断错误而受伤。因此，她最初支持逐光会建立的感染登记、隔离和治疗制度。

她并不认为所有限制都是迫害。在最混乱的阶段，她甚至曾主动说服患者接受隔离，因为她相信这是保护患者家人与其他居民的必要措施。

逐光会成立后，白芷也曾真心感谢这个组织。是逐光会维持了医院能源，运来了药品，也让她和同事能够继续救人。

## 五、她为什么会发现稳定感染者

白芷发现稳定感染者，并不是因为她进行了一场秘密实验。

原因恰恰很普通：她是年轻医生，所以被安排负责大量枯燥、重复、容易被资深研究人员忽视的随访工作。

她需要定期确认患者：

- 是否继续出现神经异常；
- 是否具有攻击倾向；
- 是否仍存在传播风险；
- 是否按时服药；
- 是否需要再次接受治疗；
- 是否能够恢复正常社会生活。

逐光会的主要研究力量更关注感染者失控、药物疗效和紧急处置。白芷却在一次次普通谈话和复查中发现，有一部分患者没有按照预测继续恶化。

他们可能出现过身体变化，却仍然：

- 记得自己的家人；
- 能够稳定交流；
- 保持原本的性格；
- 没有持续感染身边的人；
- 可以工作和生活；
- 对污染环境表现出异常耐受性。

最初，白芷也认为这只是少数暂时稳定的病例。但随着记录时间增加，她发现这些人之间存在共同特征。

她开始怀疑：

> 有些感染者不是停留在“失控之前”，而是已经进入了另一种稳定状态。

## 六、她真正提出的观点

白芷从来没有宣称：

- 所有感染者都安全；
- 所有隔离都应该立即取消；
- 治疗完全没有意义；
- 感染是一种应该被鼓励的进化。

她真正提出的观点非常有限：

> “目前的分类可能不完整。”

她认为逐光会不应该只把感染者分成：

- 尚未失控；
- 正在恶化；
- 已经失控。

她建议增加一个新的临床分类：

> **长期稳定感染状态**

她希望为这些患者建立单独的观察、生活和治疗标准，而不是继续把他们视为等待失控的人。

这一要求看似只是医学分类调整，却会动摇逐光会大量现有政策。

如果稳定感染者被正式承认，那么：

- 强制治疗是否仍然合理；
- 长期隔离是否仍有必要；
- 感染者是否可以恢复居民身份；
- 逐光会过去处理过的病例是否需要重新审查；
- 感染是否仍能被定义为必须彻底消灭的疾病；

这些问题都会被重新打开。

## 七、年轻带来的勇气

白芷敢于怀疑，部分原因确实是她年轻。

她还没有完全习惯医疗体系中的沉默规则。

资深人员知道哪些问题不适合公开讨论，哪些报告需要换一种措辞，哪些结论应该等待上级决定。

白芷却会直接询问：

- 为什么这名患者已经稳定一年，档案仍写着持续恶化；
- 为什么治疗后重新感染被算作患者不配合，而不是治疗方案失效；
- 为什么适应污染被记录为异常退化；
- 为什么长期稳定病例没有进入公开统计；
- 为什么医生需要先考虑结论会不会引发恐慌，再决定是否承认观察结果。

她并非不理解公共风险。她只是尚未接受“有些真实情况最好不要被说出来”是一种正常的工作方式。

她相信医学制度的权威应该来自能够接受质疑，而不是能够让质疑消失。

## 八、性格与习惯

### 表面性格

- 温和；
- 有耐心；
- 说话直接但不刻薄；
- 面对病人时很少使用专业术语压人；
- 不擅长公开演讲；
- 在大型会议上容易紧张。

### 内在性格

- 对具体的人极其敏感；
- 很难接受为了统计结果忽略个体；
- 相信证据，但也相信患者对自身感受的描述；
- 面对明显不合理的事情时，会突然表现出超出年龄的固执；
- 不喜欢仅仅因为对方职位更高便无条件服从。

### 工作习惯

- 会在正式病历之外记录患者说过的重要话；
- 习惯给病例建立时间线，而不是只看最近一次检查；
- 随身携带一本纸质小册子，防止电子记录被修改或丢失；
- 查房时会先叫患者名字，再确认编号；
- 紧张时会反复整理笔和记录板。

## 九、缺点与风险

白芷不是永远正确的完美医生。

### 过度相信个体经验

她容易因为长期接触某名患者，而低估其可能对其他人造成的风险。

### 不擅长政治判断

她认为只要证据足够，制度就会修改错误结论，因此低估了政策、舆论和权力对医学决定的影响。

### 容易把沉默理解为背叛

江晚等人可能只是认为证据还不充分，白芷却可能认为他们正在向逐光会妥协。

### 会为了保护患者违反程序

她可能：

- 延迟上报某次异常检测；
- 为患者争取额外观察时间；
- 擅自复制即将被回收的资料；
- 把患者从强制治疗名单暂时转入复查状态；
- 在未经批准的情况下向患者说明稳定感染的可能。

这些行为有善意，也确实可能造成风险。

## 十、她曾经犯过的错误

在一名患者长期保持稳定后，白芷曾支持减少其隔离限制。

该患者后来因为药物中断、污染暴露或强烈刺激，短暂进入失控状态，并导致一名医护人员受伤。

患者最终恢复意识，没有造成死亡。

但这次事件成为逐光会反对稳定感染分类的重要证据。

白芷没有隐瞒这件事。她认为这证明稳定状态需要管理，而不是证明稳定状态不存在。

但她对受伤医护人员始终怀有愧疚。

这件事也让她不再能够简单地说：“只要相信感染者就够了。”

她真正坚持的是：

> 风险必须被记录，但人也不能因为存在风险就被永远取消作为人的资格。

## 十一、与江晚的关系

江晚曾参与白芷的专业培训和病例评审，可以视为白芷半个导师。

白芷非常尊敬江晚。她知道江晚拥有自己缺少的专业经验，也知道江晚失去过丈夫和孩子。

江晚是最早认真阅读白芷稳定病例记录的人之一。

她没有否认白芷的观察，但认为：

- 样本数量仍然不足；
- 观察时间仍然不够；
- 稳定状态可能存在复发；
- 过早公开可能诱导感染者拒绝治疗；
- 社会上可能出现主动感染行为。

江晚曾要求白芷暂时停止公开讨论，继续收集资料。白芷最初接受了。

但当逐光会开始回收病例、重新修改部分档案，并准备对长期稳定患者进行强制治疗时，她认为继续等待已经不再是谨慎，而是在默许伤害发生。

两人的分歧不是“谁支持感染者”，而是：

> 江晚认为错误公开结论可能害死很多人。

> 白芷认为继续隐藏观察结果正在伤害具体的人。

白芷失踪前，可能把一份完整记录交给江晚。

她并不确定江晚是否会公开它，但她相信江晚至少不会销毁它。

## 十二、与逐光会的冲突

逐光会最初没有因为白芷提出疑问就立刻逮捕她。

她先后经历：

1. 被要求修改报告措辞；
2. 被取消部分病例访问权限；
3. 被调离长期随访项目；
4. 被要求接受内部纪律调查；
5. 被指控传播未经确认的医学结论；
6. 被限制与患者和外部居民接触。

逐光会对她的指控并非完全虚构。

她确实违反过程序，也确实让部分患者提前知道了尚未正式确认的稳定感染概念。

但逐光会真正无法容忍的，是她拒绝承认这些病例只是暂时没有恶化。

她被带走或失踪的具体方式仍待设计。

重要的是：逐光会可以宣称这是为了保护患者、证人和研究资料，而玩家无法在事件初期确认她究竟遭遇了什么。

## 十三、玩家第一次认识她

玩家第一次遇见白芷时，她不应该正在发表反抗逐光会的演讲。

更适合的场景是：她在医院中反复询问一名感染者一些看似普通的问题，例如：

- 最近是否仍然做梦；
- 是否还能分辨熟悉的人；
- 接近丧尸时身体有什么感觉；
- 是否记得感染前最喜欢的食物；
- 是否会在污染区域感觉更加清醒。

逐光会工作人员认为这些问题与治疗无关。

但白芷正在通过这些细节判断患者的人格、记忆和身体是否真正稳定。

玩家最初可能只觉得她是一名认真但有些奇怪的年轻医生。直到后来，才发现这些问题组成了最早的稳定感染者长期观察记录。

## 十四、她对玩家的态度

白芷不会因为好感度高就直接交出所有秘密。

她更重视玩家如何对待具体的人。

她会观察玩家是否：

- 在感染者失控前就主动攻击；
- 愿意听患者完整表达；
- 只把感染者当作进入污染区的工具；
- 为获得证据而故意让患者承担风险；
- 选择性公开支持自己观点的线索；
- 在医院资源不足时如何作出决定。

玩家可以通过行动赢得她的信任，也可能让她认为玩家和逐光会一样，只是想获得定义他人的权力。

## 十五、人物核心

白芷代表的不是“年轻人一定比年长者正确”。

她代表的是：

> 一个仍然相信制度应该兑现自身承诺的人。

梦屿教会她，每一个普通人的生命和梦想都值得被认真对待。

当逐光会要求她为了整体秩序忽略少数异常病例时，她无法把这种做法视为正常。

她最大的勇气来自年轻。

她最大的危险也来自年轻。

她还没有学会什么时候应该沉默，也没有完全理解一句真实的话在错误的时间被说出来，可能造成多大的后果。

但也正因为如此，她会提出那些所有人已经习惯不再追问的问题：

> “如果他们仍然知道自己是谁，我们凭什么替他们决定，他们已经不再是人？”

## 十六、待设计事项

- 白芷被带走、隔离或失踪的具体过程；
- 她是否主动留下多份资料；
- 她是否会在第三或第四阶段重新出现；
- 那名短暂失控患者和受伤医护人员的身份；
- 她交给江晚的记录是否完整；
- 她的最终立场是否会因玩家行为改变。
