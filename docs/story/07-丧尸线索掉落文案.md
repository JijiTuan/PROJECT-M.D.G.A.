# 丧尸线索掉落文案

状态：**掉落部分已实装；保底发放仍为未实装草案**。

以下线索池和掉落概率最初是未来扩展用的文案草案；其中 12 条线索与随机掉落规则已在
DreamingFishCore 1.21.1 分支实装，关键线索的剧情保底发放尚未实装。

## 零、实装记录

- 实装内容：12 条线索正文 + 普通丧尸/攻城丧尸随机掉落 + 收录去重。
- 触发入口：**被真人玩家击杀**的普通丧尸（僵尸、尸壳）与攻城丧尸各有 **0.01%** 概率
  掉落一张"残页"物品；玩家右键残页后记入随记本（`Item_FragmentPage` → `StoryBookDataManager`）。
- 概率与开关由 `config/dreamingfishcore/clue_drop.json` 控制（`enabled` /
  `normalZombieDropPercent` / `siegeZombieDropPercent`），**使用小数百分比**，
  服主可不改代码调整（例如 `0.5` 表示 0.5%）。
- 线索正文随模组内置，首次开服写入 `config/dreamingfishcore/data/fragment_data.json`；
  之后以该文件为准，可直接编辑增删。
- 玩家已收录的线索不再重复掉落；收齐当前线索池后不再掉落。
- 幸存者与感染者掉落规则完全一致，不做身份专属线索（与 04 文档一致）。
- **尚未实装**：关键线索 `01 / 04 / 08 / 11` 的剧情保底发放；上线前应由剧情事件（建设里程碑、
  疗程完成、调查事件等）发放，避免玩家因概率问题长期缺页。

> 下方第二节表格中的 5% / 20% 是最初的设计建议值；当前实际运行值是两种丧尸各 0.01%，
> 以本节为准。改动原因：线索属于长期收集内容，过低概率下更需要依赖保底与剧情事件发放。

当前两阶段的完整运行说明见 [当前实装剧情](当前实装剧情/README.md)。
不要根据本文件修改任务、阶段或丧尸配置；需要启用保底线索时，应先单独实现并在这里登记实际触发入口。

## 一、使用说明

- 每条线索对应随记本残页（`FragmentData` 字段：id / stageId / chapterId / authorName / title / time / content）；
- `id` 为暂定编号，落地时由重构剧情系统的 AI 分配稳定 ID；`stageId` 建议
  `dreamingfishcore:dream_beginning`（本幕不新增阶段）；
- `chapterId` 建议：1 = 感染者与治疗；2 = 逐光会与基地；3 = 远处与未来（伏笔）；
- `content` 内部换行即 `\n`（与 `FragmentData.getContentLines()` 一致）；
- 文案遵守 04 文档线索规则：**不显示真假标签**；一条线索同时包含原始观察、记录时间、
  记录者立场、方法或缺失上下文；氛围线索可误导也可佐证；核心事实多来源。

## 二、掉落规则建议（设计意图，具体实现交给剧情系统重构）

| 规则 | 建议值 |
|---|---|
| 普通丧尸 | 约 5% 掉落一条"沾灰的残页"（从该玩家尚未收录的池中随机取 1 条） |
| 攻城/特殊丧尸（siege 系） | 约 20%，或击杀时若该玩家仍有未收录线索则必掉 1 条 |
| 去重 | 玩家已收录的线索不再掉落；同一残页全服共享内容，个人收集状态独立 |
| 保底 | 关键线索（01/04/08/11）在剧情事件中发放：建设里程碑、疗程完成、调查事件等，避免脸黑断线 |
| 身份 | 幸存者与感染者掉落/阅读完全一致，不做"感染者专属线索" |
| 物品 | 掉落的是一份物品（如"沾灰的残页"），右键后记入随记本；物品本身无稀有度 |

### 02 逆转变异药剂使用说明

| 字段 | 值 |
|---|---|

| title | 逆转变异药剂使用说明（应急版） |

> 用途：已通过医学评估、确认人格与记忆稳定的感染者，进行早期逆转治疗。
