## Overview

均克饮品集团是旧世界大型饮料企业。

公司主要生产日常饮品、功能饮料以及长期储存饮品。

其产品曾遍布城市便利店、公共设施和应急储备中心。

## Products

- Junko Pure
- Junko Energy
- Junko Recovery Drink

## Incident Note

灾难发生后，部分饮品库存仍存在于废弃商业设施中。
