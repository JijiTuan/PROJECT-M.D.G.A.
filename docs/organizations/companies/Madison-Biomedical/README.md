## Overview

麦迪森生物科技集团是旧世界最具影响力的生物医学企业之一。

公司早期专注于创伤治疗、器官修复与神经恢复技术，后逐渐参与生命模板与重生技术研究。

其研究成果成为梦屿生命保障体系的重要基础之一。
