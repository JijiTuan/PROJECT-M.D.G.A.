# 第 2 阶段：余梦期

## 基本信息

- 阶段 ID：`dreamingfishcore:afterdream`
- 阶段名称：余梦期
- 主要 NPC：白芷、江晚
- 主要地点：人类逐光联合会保护区的医疗接待点
- 推进方式：个人医疗流程与世界定时事件并行

## 阶段开场

当前开场说明为：

> 随着危机的进一步发展，逐光会发现阿拜多斯发生了多起感染事件。

世界进入第二阶段后，不会等待所有玩家处于同一个个人任务节点。在线玩家立即接到新内容，离线玩家之后上线时也会收到自己的医疗私信和任务。

## 阶段启动时立即发生的内容

### 1. 清理第一阶段遗留状态

- 为所有玩家统一完成第一阶段的“建设逐光会基地”；
- 关闭仍在显示的第一阶段引导；
- 保留玩家此前的成员选择。

### 2. 发布医疗接待公告

公告标题：

```text
【逐光会】阿拜多斯感染者医疗接待开放
```

公告说明阿拜多斯已经出现多起感染事件。出现感染症状的居民以及愿意陪同的人，应前往逐光会大楼门口，由医疗组确认感染情况；符合条件的感染者可领取用于当前医疗流程的基因复活药水。

### 3. 发布生命恢复异常公告

公告标题：

```text
【逐光会】生命恢复异常通告
```

公告以逐光会医疗组的口吻说明：感染危机恶化后，未经药物或医疗处理的伤势只能自然恢复到最大生命值的约 50%，感染点数和重生点数也不再随时间自行恢复。药品、医疗处理及保护区内的特殊恢复效果仍然有效。

这部分记录的是当前已经发布给玩家的剧情说明；具体数值规则仍以游戏代码和服务器配置实际运行结果为准。

### 4. 白芷发送医疗说明

白芷会向每位玩家发送医疗私信。内容会说明：

- 梦屿原本拥有住房、医疗、教育、能源和重生等公共保障；
- 当前灾难使原有机构难以单独处理不断扩大的感染问题；
- 逐光会是由医院、能源、重生、研究、救援和社区安保人员组成的临时联合组织，并非取代原有社会；
- 江晚负责医疗接待、治疗标准、药品与病例记录。

玩家读完私信后，才会完成“阅读白芷的医疗说明”，并获得前往医疗接待点的引导。

### 5. 启动丧尸破坏能力倒计时

进入第二阶段时会开始一个 48,000 游戏刻的世界倒计时，约等于 2 个游戏日。倒计时从第二阶段启用时的世界时间开始计算，并保存在存档中，服务器重启不会重新开始。

倒计时结束前，第二阶段剧情会保持丧尸挖掘方块的能力关闭；听力、开门、破门、广播、围堵和保护区规则继续沿用当前丧尸阶段配置，不由这条剧情事件重设。

## 个人医疗流程

### 1. 阅读白芷的医疗说明

玩家阅读私信后：

- 完成任务“阅读白芷的医疗说明”；
- 获得前往逐光会医疗接待点的地点引导。

### 2. 前往医疗接待点

玩家进入逐光会医疗接待区域后：

- 完成任务“前往逐光会医疗接待点”；
- 获得寻找江晚的 NPC 引导。

### 3. 与江晚完成首次接待

只有玩家位于逐光会医疗接待区域内，与江晚交互才会推进医疗剧情。首次交互会先显示江晚的接待说明，再通过终端检查玩家的感染状态。

首次接待会尝试向玩家发放一瓶基因复活药水。如果背包没有空位，流程不会错误推进，玩家清理背包后可以重新与江晚交互领取。

### 4. 根据感染状态给出结果

#### 一级感染或早期感染

江晚会说明当前药水可以处理这一阶段的感染。玩家实际使用药水、感染值归零后，才算完成感染复核与治疗。

#### 未感染但存在感染值

江晚会说明药水可以清除感染值，但不会改变玩家原有身份。玩家实际使用药水、感染值归零后完成这一项任务。

#### 二级感染或重症感染

江晚仍会登记检查结果并发放药水，但会明确说明当前药物无法治愈这一状态，并同时说明医疗组有一份**三次早期逆转疗程**方案。系统不会把该玩家错误标记为已经完成治疗。

江晚的长对话会按页面显示；短对话使用较矮的对话框。

### 5. 二级感染的三次早期逆转疗程

二级感染不再停在“暂无治疗方案”。完成首次接待（结果对话展示过“药剂无效”）之后，玩家再次与江晚交互即可开始疗程：

| 步骤 | 实际行为 |
| --- | --- |
| 开始 | 第一次治疗在当次交互内完成；江晚说明规则（三次、每次间隔一个游戏日、不做就记录） |
| 间隔 | 每次治疗后需间隔 **1 个剧情活动日（24,000 tick，仅在线累计）**；未到间隔时江晚只提示等待，不推进状态 |
| 治疗 | **院内治疗**：由江晚在接待点执行，不发放也不消耗物品，玩家无法用别的方式跳过 |
| 终检 | 第三次治疗之后再次交互即终检：感染读数归零、感染状态解除，玩家恢复为幸存者 |
| 引导 | 疗程期间显示“接受早期逆转疗程”引导；终检后关闭，并保留既有的面具引导 |
| 任务 | 不新增任务：疗程与终检沿用“完成江晚的感染复核”这一条 |

治疗间隔按剧情活动时间计算，服务器无人时不会消耗间隔；服务器重启后从存档继续。

### 6. 终检后的第 3 / 7 天随访

终检完成后，白芷负责长期随访：

- 从终检时间起算，第 3 天与第 7 天（各 3 × 24,000 / 7 × 24,000 剧情活动 tick）各发一次私信提醒；
- 玩家在医疗接待点**与白芷交谈即完成一次复核**，记录写入个人进度；
- 逾期、漏做或延后**没有任何惩罚**，只记录实际发生过什么；第 7 天提醒不要求第 3 天已完成；
- 有待办随访时终端显示“完成随访复核”引导，完成后自动关闭。

## 防护面具流程

### 倒计时起点

防护面具的 2 个游戏日不是从第二阶段开场计算，而是从全服第一名玩家完成江晚首次医疗接待时开始计算。

该倒计时使用剧情活动时间，总计 48,000 游戏刻。只有至少一名已认证玩家在线时才会累计，服务器无人在线的时间不计算在内；重启后会从存档中继续。

### 开始发放

倒计时结束后发布公告：

```text
【逐光会】防护面具开始发放
```

已经完成首次接待的玩家，需要重新开启一次与江晚的对话并再次交互，才能领取面具。如果背包已满，物品不会丢失，玩家之后可以重试。

江晚目前会这样说明面具：

> 防护面具已经准备好了。至少在目前可以阻止感染的传播，但不能治疗感染，也不能代替医疗复核。请收好并在需要时佩戴。

### 面具发放后的感染变化

当全服第一只防护面具真正进入玩家背包后，世界才会切换到面具发放后的感染规则：

- 新感染的感染值上限由 100 提高到 200；
- 新产生的一级感染者会获得约 1 个剧情活动日的早期治疗窗口；
- 在治疗窗口内完成治疗可以阻止恶化；
- 超时后会转为更严重的感染状态。

全服第一次发生这种感染恶化时，会发布公告：

```text
【逐光会】感染恶化与传播风险变化
```

公告会说明新病例的感染过程已经发生变化，防护面具不能保证抵御所有新变化，现有药物也只适用于较早阶段。

## 丧尸恢复破坏能力

第二阶段启用约 2 个游戏日后，系统会发布公告：

```text
【逐光会】丧尸开始恢复破坏能力
```

公告的世界观内容为：

- 丧尸病例最早来自梦屿之外的外缘带；
- 当地底层居民缺乏社会保障，遭受污染后无法及时进入医院治疗，原有疾病又加重了感染；
- 部分感染者因此直接发展为重症并转化为丧尸；
- 当前研究认为，这种疾病表现出压制并控制正常人类的倾向；
- 新的观测显示，丧尸正在逐渐回忆感染前身体的行动方式，因此开始懂得破坏方块；
- 逐光会保护区域使用了特殊干扰技术，进入保护区的丧尸会忘记如何破坏方块。

公告发布时只开启当前丧尸阶段的挖掘能力，不会覆盖听力、开门、破门和其他已经配置好的能力。
