# 第 1 阶段：梦的开始

## 基本信息

- 阶段 ID：`dreamingfishcore:dream_beginning`
- 阶段名称：梦的开始
- 主要 NPC：白芷、周岑
- 主要地点：阿拜多斯、逐光会基地
- 推进方式：每位玩家分别推进，服主统一切换世界阶段

## 阶段内容

灾难来临后，阿拜多斯成为幸存者暂时落脚的地方。玩家通过临时安置通知来到小镇，在学校找到从事医疗志愿工作的白芷，随后经她介绍认识周岑，并决定是否加入正在筹建的人类逐光联合会。

加入与否只改变玩家在第一阶段的个人选择、物资和引导，不会阻止玩家进入第二阶段。

## 玩家流程

### 1. 阅读阿拜多斯临时安置通知

玩家先在梦屿广播中阅读公告：

```text
阿拜多斯 · 临时安置通知
```

通知会说明阿拜多斯提供临时床位、基础物资和医疗帮助，并引导玩家前往登记点附近：

```text
X 9890，Y 151，Z 1771
```

只有读完这条公告，玩家的第一阶段个人流程才会正式开始，并获得前往阿拜多斯的引导。

### 2. 抵达阿拜多斯

玩家进入阿拜多斯区域后：

- 完成任务“抵达阿拜多斯”；
- 收到白芷的私信“到学校来找我”；
- 获得前往学校寻找白芷的引导。

### 3. 在学校与白芷交谈

玩家必须在阿拜多斯区域内与白芷交互，才会推进剧情。白芷会说明：

- 她正在协助安置点处理医疗工作；
- 大家的伤势和感染情况仍在变化；
- 医院、救援人员和居民正在筹建逐光会；
- 周岑负责说明逐光会的具体安排。

交谈完成后：

- 完成任务“去学校见白芷”；
- 收到周岑的私信“临时联络已经接通”。

### 4. 通过私信了解逐光会

玩家在周岑的私信中选择：

```text
我是白芷介绍来的，想听听具体安排。
```

随后会收到正式介绍“人类逐光联合会”。周岑会说明逐光会目前负责连接救援、医疗、补给与居民协作，并让玩家在两种选择中作出决定。

### 5. 作出选择

#### 加入逐光会

玩家的成员身份会被记录，并收到“成员登记完成”私信和一次性起步物资：

- 铁镐 × 1
- 铁斧 × 1
- 面包 × 16
- 石砖 × 64
- 橡木板 × 64
- 火把 × 32

之后会出现“建设逐光会基地”的引导。这个任务代表第一阶段剩余时间里的公共建设方向，不是进入第二阶段必须由每位玩家亲自完成的硬性条件。

#### 保持独立

玩家的独立选择会被记录，并收到“选择已记录”私信。玩家不会获得成员起步物资和基地建设引导，但仍可正常使用阿拜多斯的居住、医疗和交易设施。

## 任务清单

| 任务 | 完成条件 |
| --- | --- |
| 抵达阿拜多斯 | 进入阿拜多斯区域 |
| 去学校见白芷 | 在阿拜多斯区域内与白芷完成交谈 |
| 了解逐光会 | 在周岑私信中选择加入或保持独立 |
| 建设逐光会基地 | 仅向加入者显示；世界切换到第二阶段时统一完成 |

## 阶段结束与切换

第一阶段没有按在线人数或任务完成率自动结束的逻辑。服主决定剧情准备好后，手动把世界切换到第二阶段。

切换时系统会：

- 为所有玩家统一完成“建设逐光会基地”，避免旧任务继续显示在右下角；
- 关闭第一阶段残留的活动引导；
- 保留玩家加入逐光会或保持独立的选择记录；
- 启动第二阶段“余梦期”。
